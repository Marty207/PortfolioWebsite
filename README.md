# Martin Donev Portfolio

Welcome to my personal portfolio website! This site showcases my projects and provides information about my background as a Computer Science student at Illinois State University.

## Project Overview

This portfolio is designed to highlight my skills, projects, and contact information. It features a clean and user-friendly interface with easy navigation.

## Features

- **Header**: Displays my name, "Martin Donev," and my title as a "CS Student at Illinois State University."
- **Projects Section**: A dedicated area to showcase the projects I have worked on, including descriptions and links.
- **Contact Information**: Provides my phone number and email for potential employers or collaborators to reach out.
- **Footer**: Contains a "Contact Me" section for easy access to my contact details.

## Getting Started

To run this project locally, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/martin-donev-portfolio.git
   ```

2. Navigate to the project directory:
   ```
   cd martin-donev-portfolio
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm start
   ```

Your browser should automatically open to `http://localhost:3000`, where you can view the portfolio.
